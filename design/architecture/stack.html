Constraints

  • FluentAssertions pinned to 7.x (Apache-2.0). Never upgrade to 8.x — 8.x is commercially licensed (Xceed). License-driven hard constraint.
  • net48 target only. Dictated by RimWorld's Mono runtime; cannot target modern .NET runtimes.
  • RimWorld assemblies are not NuGet. Assembly-CSharp + Unity modules are HintPath references resolved from a local RimWorld install (RimWorldManagedDir / RIMWORLD_DIR); build requires the game installed.
  • LordKuper.Common is upstream, read-only. Consume its public surface; do not fork (resolved from ..\..\rimworld-common\1.6\Assemblies, overridable via LORDKUPER_COMMON_DIR).
  • LordKuper.Common runtime dep is v1.6-only (modDependenciesByVersion); 1.3–1.5 do not depend on it at runtime.
  • SimpleSidearms reference resolved from a local Workshop path (SimpleSidearmsDir / SIMPLE_SIDEARMS_DIR); compile-only.
  • Compile-only references must not ship. Harmony ExcludeAssets=runtime; LordKuper.Common / SimpleSidearms Private=False — runtime copies come from the player's installed mods.
  • Warnings-as-errors, all configs. TreatWarningsAsErrors=true, WarningLevel 9999 — any analyzer warning fails the build.
  • Published mod. Live on Steam Workshop; changes affect existing subscribers and saved games.
